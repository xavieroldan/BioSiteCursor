n8n Job Scout

Automatización + IA · v0.1 disponible

Workflow de n8n que lee ofertas de empleo de feeds RSS, las normaliza, elimina duplicados entre ejecuciones y usa Claude para puntuarlas de 0 a 100 según un perfil profesional, con motivos y alertas. Cada mañana envía por Telegram un resumen con las mejores. El código de los nodos se genera desde JavaScript testeado (19 tests) y se valida en CI con GitHub Actions. Se despliega con Docker Compose.
