AI Sprint Assistant

Scrum + CI/CD + AI · v0.1 available

GitHub Action that uses Claude to review every pull request against its user story and the team's Definition of Done. It posts a single comment with a summary, change type, story alignment and every DoD item as met, not met or unknown with evidence, It also runs automatic checks without AI (linked story, acceptance criteria, tests, PR size), ships user story templates and can block the merge. Dependency-free, 37 tests and it reviews its own repository.

n8n Job Scout

Automation + AI · v0.1 available

n8n workflow that reads job offers from RSS feeds, normalises them, removes duplicates across runs and uses Claude to score each one from 0 to 100 against a professional profile, with reasons and red flags. Every morning it sends a Telegram digest with the best matches. The Code-node logic is generated from tested JavaScript (19 tests) and validated in CI with GitHub Actions. Deployed with Docker Compose.
